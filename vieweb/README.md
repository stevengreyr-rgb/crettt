# Nexo / Vieweb.page — sitio premium (estático)

Sitio de una página, sin build. Sube esta carpeta tal cual a Netlify
(arrastrar y soltar en app.netlify.com/drop) o conéctala al repo con
"Publish directory" = `vieweb`.

- Textos, precios y enlaces de WhatsApp (ES/EN): `js/data.js`
- Diseño: `css/styles.css` · Lógica: `js/main.js`
- `_redirects`, `robots.txt`, `favicon.svg`: los de tu sitio actual.

Pendiente: imagen `og.jpg` (1200×630) para compartir en redes; las capturas de
ejemplo son maquetas ilustrativas hasta que haya capturas de sitios reales.
